# 제반 사항
- 유/무선망을 동시에 가용한 상태에서, 무선망을 통해 로컬 장치에 접속하려고 할 때, 메트릭 문제로 유선망이 끊어지거나, 유선망의 장치로 무선 장치를 찾게 되어 실패할 수 있음
- 메트릭 설정/방화벽 설정/라우팅 설정 필요
- 윈도우 설정은 11 기준으로 작성함
# 과정 
## 1. 메트릭 설정
- 유선, 무선 네트워크의 메트릭 수동으로 지정 - 인터넷 접속 우선순위
- 설정 > 네트워크 및 설정 > 고급 네트워크 설정
	- 이더넷(숫자 상관 없음) > 추가 어댑터 옵션 > 인터넷기반 프로토콜 버전 4 > 고급
		- 자동 메트릭 해제
		- 인터페이스 메트릭 낮은 값(1~50)
	- WIFI(숫자 상관 없음) > 추가 어댑터 옵션 > 인터넷기반 프로토콜 버전 4 > 고급
		- 자동 메트릭 해제
		- 인터페이스 메트릭 높은 값(50~100)
## 2. 무선 연결망 확인 
- 양쪽의 장치의 ip 주소 확인 
	- ```powershell
ipconfig
	  ```
	- 각 장치의 무선랜 wifi의 ip 주소 확인 
- 양쪽의 장치에서 다음을 실행
	- ```powershell
netsh wlan show interfaces
arp -a
	  ```
	- `netsh` 결과의 SSID와 대역이 동일해야함
		- 설명의 연결 장치를 확인해야함
	- `arp`의 자신 장치 무선 ip 인터페이스에서 상대 장치 ip 주소가 존재해야함 
	- 둘 중 하나라도 안되어있는 경우, 동일 무선랜 아님
## 3. 로컬 연결 무선 우선 라우팅
- 다음을 실행
	- ```powershell
route print
	  ```
	- 무선랜 와이파이 아답터의 인덱스 확인
		- `netsh`에서 확인한 설명의 장치
- 고정 라우트 추가 
	- ```powershell
route add 192.168.0.0 mask 255.255.255.0 192.168.0.1 metric 5 if <Wi-Fi-Idx> -p
	  ```
