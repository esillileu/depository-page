- 통계 분석 기초
	- 변수
		- 특정 집합에서 값을 취하는 함수의 [[Domain|정의역]]상의 기호
		- 통계학에서는 사건에 값을 할당하는 함수
			- 확률 변수 - 확률 공간 위에 정의된 가측 함수
		- 독립변수 - 설명 변수
		- 종속변수 - 결과 변수
	- 척도 - 변수의 측정 수준
		- 명목 - 크기나 순서 없음
		- 서열 - 순서는 있으나 간격 없음
		- 등간 - 순서가 있고 간격이 일정하나 절대 0 없음
		- 비율 - 등간이며 절대 0 존재
	- 분석 방법
		- 회귀 - 종속변수가 등간/비율일 경우
		- 로지스틱 회귀 - 종속 변수가 명목/서열일 경우
		- 로짓 분석 - 종속변수와 독립변수가 모두 명목/서열일 경우
