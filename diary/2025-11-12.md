# 주요 작업 및 결과
- cs 알고리즘
	- 카데인 알고리즘
		- 전 단계까지의 최대 부분합을 저장
		- 최대 부분합과 원소의 합을 현재 원소와 비교하여 큰 값을 저장
		- 최대 부분합과 전역 최댓값을 비교하여 갱신 
	- 누적합(prefix) 이용
		- 0에서부터의 누적합을 미리 계산해두면 이후 부분 누적합을 모두 O(1)으로 접근 가능
		- 특정 점까지의 누적합도 계산 가능 - 특정 점에서 0까지의 거리를 개수만큼 빼기 
	- 순환 수열의 인덱스는 mod 연산으로 역산 가능
		- 1개씩 증가한 뒤 k 번째 수: (k-n) mod L
		- 1개씩 감소한 뒤 k 번째 수: (k+n) mod L
- 트랜스포머
	- 하나의 시퀀스를 동일 의미의 다른 시퀀스로 변환 
		- 한 시퀀스의 문맥을 인코딩
		- 이를 바탕으로 순차적으로 다른 시퀀스 생성
		- 학습 과정에서 순차 생성 모사를 위한 마스킹
	- 어텐션
		- 메커니즘
			- Q, K, V 행렬 생성
				- 입력은 (n, H)
				- 각 가중치(Wq, Wk, Wv)는 각각 (H, H) - 헤드(h)에 따라 나눔 h*(H, H/h) 
				- 입력에 가중치를 각각 곱해 Q, K, V 생성(n, H)
			- 어텐션 스코어 - Q, K를 곱하고 스케일링해서 모든 토큰에 대한 상호 관계를 스코어화 (n, n) : 참조 강도
			- 어텐션 가중치 - 소프트 맥스로 어텐션 스코어 (n, n) : 정규화된 참조강도
			- 어텐션 결과 - 어텐션 가중치를 V에 곱해 문맥 벡터 계산(n, H) : 문맥 벡터 
		- 종류
			- 셀프 어텐션 - Q, K, V 입력이 모두 자기 자신
			- 크로스 어텐션 - Q와 K, V 입력이 다름
		- 특징
			- Q는 질문, K는 정보 요약, V는 정보 내용으로 기동
			- 매커니즘 작동을 위해서는 K가 V에 의미적으로 종속이 보장되어야 함
				- 의도적으로 다르게 만든 뒤 정렬하게도 가능
	- 입력
		- 임베딩 레이어로 토큰을 임베딩 벡터로 변환(n, H)
		- 입력 임베딩에 포지셔널 인코딩 결과(n, H)를 더해 입력 계산
		- 
	- 인코더
		- 입력 토큰에 대해 셀프 어텐션 적용 - 입력 토큰 마다 다른 모든 입력 토큰과의 관계를 비선형 히든스테이트 벡터로 변환
		- fc로 결합
		- 각 단계마다 잔차 연결
	- 디코더
		- 입력 토큰 순회, 이전토큰만 참조(마스킹)
		- 마스크드 셀프 어텐션으로 입력 문맥 계산
		- 입력 문맥을 Q 입력으로, 인코더 출력을 K, V 입력으로 크로스 어텐션
		- fc로 결합
		- fc, softmax로 다음 토큰 확률 변환
		- 단계마다 잔차 연결
