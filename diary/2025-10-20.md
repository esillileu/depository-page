# 주요 작업 및 결과
- gpu 아키텍쳐 특징
	- 대역폭이 넓고 응답 속도가 느림
		- 많은 데이터를 핸들링 하는데 유리
		- 동시에 병렬 처리하는 데에 유리
- 이종 프로그래밍 모델
	- gpu는 가속기임 - cpu로만 시작될 수 있음
	- nvcc
		- 엔비디아에서 제공하는 cpp 컴파일러
		- 지정자를 통해 특정 코드의 
		- 컴파일 타임에 `__device__` 실행 한정자가 있는 대상에 대해 gpu 실행 파일로 컴파일
			- `auto a = [=] __host __device__ (float temp) { } `
				- cpu, gpu 모두에서 실행 가능
	- `thrust`
		- cuda에서 제공하는 gpu 알고리즘 구현 라이브러리
		- 알고리즘의 첫 인자로 실행 정책 지정 필요
			- 실행 타임에 지정된 기기에서 실행 
			- `thrust::host`
			- `thrust::device`
	- 
- c++
	- 람다함수
		- `[<capture_type>](<parameters>) {codes}`
			- `<capture_type>` - 인클로져 스코프의 변수를 참조할 방법
				- `[=]`: 복사 
				- `[&]`: 포인터
				- `[&x]` : x만 포인터로 참조
			- `<parameters>` - 전달 파라미터
				- 타입 파라미터명으로 전달
	- `std::transform`
		- `std::transform(first, last, result, operater)`
			- `first` - 이터레이터의 첫 요소
			- `last` - 이터레이터의 마지막 요소
			- `result` - 결과 이터레이터의 첫 요소
			- `operater` - 적용할 연산
