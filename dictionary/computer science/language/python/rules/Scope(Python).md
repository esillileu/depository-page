# Scope(Python)
> [[Python|파이썬]]의 [[Scope(Python)|스코프]]
## 특징
+ [[LEGB]] 규칙을 따름
+ 제어 [[Block|블록]]에 의한 스코프 생성 없음
	+ if, for, while, try, [[with Statement|with]], match
+ 정의 [[Block|블록]]에 의해 스코프 생성
	+ def, lambda, class
+ 모듈 전체가 하나의 전역 스코프를 가짐
