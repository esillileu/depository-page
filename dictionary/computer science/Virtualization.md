# Virtualization
> 물리적 자원의 추상화
## 특징
- 하드웨어 자원의 추상화 - 인터페이스 제공
	- 자원을 분할-통합-재구성하여 논리 단위로 제공
		- 하나의 물리 환경에서 여러 가상 환경 사용
		- 여러 물리 환경에서 하나의 가상 환경 사용
- 
## 유형
- 리소스 가상화 - 물리적 리소스를 가상화
- 플랫폼 가상화
	- 데스크톱 가상화 - OS와 앱을 포함하는 사용자 환경 가상화 
	- 시스템 가상화 - OS 전체를 가상화
		- 하이퍼바이저
	- 컨테이너 가상화 - OS 커널을 공유하며 프로세스 단위 격리
		- 컨테이너
		- 도커
	- 에플리케이션 가상화 - OS의 가상화 레이어를 이용한 프로세스 격리
