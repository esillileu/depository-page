# chmod
> 리눅스의 파일, 디렉토리의 접근 권한 변경 명령어
## 특징
- 파일의 퍼미션 비트 수정
- 사용자에 따른 권한 조정
	- 대상
		- `u` - 사용자(user)
		- `g` - 그룹(group)
		- `o` - 기타(other)
		- `a` - 모두(all)
	- 권한 
		- `r` - 읽기(read)
		- `w` - 쓰기(write)
		- `x` - 실행(execute)
- 파일 권한 표시 
	- `drwxrw-r--` - [[ls|ls -l]]로 확인 가능
	- 10자리 문자열
		- `-` - 빈칸
		- 첫자리 - 타입
			- `-` - 파일
			- `d` - 디렉토리
			- `l` - 링크
			- `c` - 문자 디바이스 파일: 터미널, 시리얼포트
			- `b` - 블록 디바이스 파일: 하드디스크, USB
			- `p` - 파이프
			- `s` - 소켓
		- 다음 세자리 마다 사용자, 그룹, 기타 권한 
## 사용
- `chmod <author_type> <file_name>`
	- `<author_type>: ([ugoa][+-=][rwx]) | ([0-9]{3})`
		+ `[ugoa][+-=][rwx]` - 심볼릭 모드
			+ `[ugoa]` - 대상
			+ `[+-=]` - 권한 추가/제거/변경
			+ `[rwx]` - 조정할 권한
		+ `[0-9]{3}` - 8진수 모드
			- `r` = 4, `w` = 2, `x` = 1
			- 합산을 통해 지정 
				- `chmod 755 file.sh` - `-rwxr-xr-x`
